# Checklist antes de cobrar o primeiro cliente

[ ] Registo/constituição da entidade e atividade confirmados
[ ] Termos de utilização publicados
[ ] Política de privacidade publicada
[ ] Regras de cancelamento/renovação publicadas
[ ] Conta empresarial confirmada pelo banco
[ ] Gateway contratado e credenciais obtidas
[ ] Backend hospedado com HTTPS
[ ] Base de dados com backups
[ ] Login e recuperação de senha testados
[ ] 2FA do administrador testado
[ ] Isolamento dos dados entre empresas testado
[ ] Webhook de pagamento testado
[ ] Renovação de +30 dias testada
[ ] Avisos 7/3/1/0 dias testados
[ ] Bloqueio após tolerância testado
[ ] Reativação após pagamento testada
[ ] Registos de auditoria testados
[ ] Teste de carga e segurança realizado
[ ] Validação contabilística/fiscal/jurídica local concluída
[ ] Só então: produção
